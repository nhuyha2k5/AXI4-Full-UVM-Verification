Each command carries the reason why the item cannot be reached. The rule followed: an item is excluded
only when the RTL or the AXI4 specification makes it unreachable, never because it was hard to hit.

Three figures are given per group so that the effect of the exclusions is visible:

* **none** - raw coverage of the merged regression;
* **unreachable only** - without the items no stimulus can reach in any configuration (loop variables,
  signals tied to constants, elaboration-time code, structurally impossible condition rows);
* **unreachable + configuration-limited** - additionally without the items marked `CONFIG-LIMITED`, which are
  unreachable only because of the verified configuration (32-bit data bus, 3 address regions per slave).
  The gate of `-MinTotal` is applied to this figure.
